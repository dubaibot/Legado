## 最新结论（根因修正）

### ③ 出包：CI 构建失败，新包从未产出（已修复）

**原判断**：出包分支错误（`build-apk.yml` 监听 main，修复在 test）。已把分支改为 test，但这只是第一步。

**精确根因**：CI 构建在 chaquopy Python 任务失败，未产出任何 APK。

- `app/build.gradle:198` chaquopy 配置 `buildPython("python3.11")`，构建机需提供 python3.11。
- `build-apk.yml:34` 构建命令 `./gradlew :app:assembleDebug --no-daemon`，**没有 `-x :app:installAppDebugPythonRequirements`**。
- CI runner（ubuntu-latest，Ubuntu 24.04）默认 python3=3.12，**无 python3.11**。
- chaquopy 找不到 python3.11 → `installAppDebugPythonRequirements` 失败 → 构建 exit 1，耗时 1m34s 早期失败，无 artifact，上传步骤 skipped。
- 本地构建一直用 `-x :app:installAppDebugPythonRequirements` 跳过该任务，所以本地从未暴露此问题。

**证据链**：
- CI run `46169630673`：failure，Build Debug APK 步骤 exit 1，无 artifact。
- 用户日志 01:28 无 `BiliDirect:` 诊断日志 → 包内是旧代码（CI 未产出新包）。
- 本地源码干净，`./gradlew :app:assembleDebug -x :app:installAppDebugPythonRequirements` 本地构建成功（11m58s）。

**修复**（commit `11ce4b0`）：
- `build-apk.yml:34`：`./gradlew :app:assembleDebug -x :app:installAppDebugPythonRequirements --no-daemon`
- 与本地构建一致。
- Python 脚本（`app/src/main/python/*.py`）仅用标准库，无第三方依赖，跳过 pip 安装无影响。

**验证**：CI 重跑后，artifact `readingD-apk` 应出现；新包播放视频须出现 `BiliDirect: resolve aid=... cid=...`。
