# 书源发现多级分类手动构建方案（设计文档 v1.0）

> 项目：阅读D（dubaibot/Legado）
> 日期：2026-10-03
> 定位：替代旧「自动大分类栏」方案；由用户从传统发现面板手动构建分类树，最多三级（一级 → 二级 → 三级），一级一栏、列表页三栏平铺展示。

---

## 一、设计目标

1. 解决"自动判断大/细分类"在真实书源中准确率低的问题（大量书源分类纯平铺，无天然层级）
2. 让用户能够按自己的理解，把任意发现项组织成最多三层的分类结构
3. 可被选择的对象不限于链接，select 下拉框内的每个选项、button、text 均可参与
4. 分类与"筛选设置"（完结/连载、男/女频、字数、时间等）分离，各自独立存储与生效

---

## 二、已确认决策（全部拍板项）

| # | 决策点 | 结论 |
|---|--------|------|
| 1 | 首次进入预填 | 自动判断一级；判断失败时**不选第一个**，直接平铺所有分类 |
| 2 | 列表页展示形态 | 三级**三栏平铺**，不做渐进式展开 |
| 3 | 失效分类处理 | **不清理**，保留显示，点击时提示失效 |
| 4 | select 辖域 | **严格限定**：父级是 select 选项时，候选仅限同一 select 值域 |
| 5 | 筛选设置 | **自动应用**：进入列表页/点击分类拉书前自动生效 |
| 6 | 辖域矩阵 | B 方案：url 分类可挂子级，候选为同面板全量 |
| 7 | 添加层级 | **不允许跳过**：添加 N 级必须先存在 N-1 级 |

## 三、入口与页面结构

### 3.1 入口调整

列表页右上角原「传统发现」按钮更名为「筛选」。点击后进入筛选页，承担分类管理 + 筛选设置两项功能。

### 3.2 筛选页布局（自上而下三个区块）

| 区块 | 内容 | 交互 |
|------|------|------|
| 已选分类 | 一级栏、二级栏、三级栏（每栏末尾「＋」） | 长按节点删除（父级删除连带子级） |
| 筛选设置 | 书源自带 select / text / 开关型 button 内嵌 | 改动即保存，自动应用 |
| 传统发现面板 | 原样渲染 text / button / select / url 分类 | 点击项 → 弹「添加分类」菜单 |

筛选页顶部提供两个操作按钮：**清空重建**（删除后重新按预填算法生成）与**清空**（全部置空）。

补充拍板（2026-10-03 会话确认）：
- 「＋」按钮点击 → 弹提示「请从下方面板选择分类添加」
- 面板点击仅弹添加菜单，**无浏览入口**（不加「浏览」项）

## 四、可选项类型与语义

| 类型 | 是否可作为分类节点 | 点击行为 | 可否挂子级 |
|------|------------------|----------|-----------|
| url 分类 | 是 | 直接加载该 url 的书籍列表 | 可以（B 方案，候选同面板全量） |
| select 选项 | 是（下拉框内每个选项独立可选） | 先执行该选项的 action 切换语境，再加载该 select 的默认列表 | 可以（候选严格限定同一 select 值域） |
| button | 是（操作型） | 仅执行其 action，不拉书 | 不可以，仅叶子节点 |
| text | 否 | 归入筛选设置区使用 | 不可以 |

- 面板项在添加菜单中以图标区分类型：url = 📄、select 选项 = ▾、button = 🔘
- 点击面板中的 select 控件时，先展开其选项列表，再点击具体选项才弹出添加菜单

---

## 五、多级分类的辖域规则

### 5.1 辖域定义

"辖域"指某个节点能够挂载下一级的候选集合。规则如下：

| 父节点类型 | 二级候选范围 | 三级候选范围 |
|-----------|--------------|--------------|
| 分段标题（无 url、占满一行） | 该标题段内全部项 | 跟随其二级节点的辖域 |
| select 选项 | 仅同一 select 值域内的其他选项 | 跟随其二级节点的辖域 |
| url 分类 | 同面板全部可选项（B 方案） | 同面板全部可选项（B 方案） |
| button / text | 不可作父级 | 不可作父级 |

### 5.2 添加菜单的可用性（不允许跳过）

点击面板可选项后弹出菜单，各选项的可用条件：

| 菜单项 | 可用条件 |
|--------|----------|
| 添加一级 | 始终可用 |
| 添加二级 | 仅当一级栏非空，且候选通过辖域过滤 |
| 添加三级 | 仅当二级栏非空，且候选通过辖域过滤 |
| 取消 | 始终可用 |

- 一级为空时，只能添加一级，其余菜单项置灰
- 二级为空时，只能添加一级或二级，不能直接挂三级
- 同名冲突处理：同名称不同引用的项显示为"名称（序号）"，长按可查看完整引用信息

---

## 六、首次进入的预填逻辑

仅当用户**从未手动编辑过**该书源分类时执行；一旦用户手动增删，预填不再覆盖。

| 判断结果 | 一级栏 | 二级栏 | 三级栏 |
|----------|--------|--------|--------|
| 面板中存在 ≥2 个分段标题 | 各分段标题名称 | 各标题段内的 url 分类 | 空 |
| 判断失败（无分段标题） | 空（隐藏一级栏） | 全部 url 分类平铺 | 空 |

预填依据书源面板结构实时生成，不写入持久化的用户树（用户保存的树独立于预填）。

---

## 七、列表页三栏平铺展示

顶栏区域从上到下最多三栏，每栏为横向滚动 chip，哪一级有内容就显示哪一级：

```
[←][第N页]  书源名（居中）      [搜索][筛选]
[一级栏：玄幻 都市 悬疑]          ← 当前高亮
[二级栏：东方玄幻 异世大陆]       ← 当前高亮
[三级栏：……]                   ← 当前高亮
[书籍列表]
```

### 点击行为

| 操作 | 结果 |
|------|------|
| 点一级项 | 一级高亮；二级栏刷新为其子级；三级栏刷新为当前二级的子级；按该项语义拉书 |
| 点二级项 | 二级高亮；三级栏刷新为其子级；拉书 |
| 点三级项 | 三级高亮；拉书 |
| 再点已高亮项 | 无操作（层级通过栏本身表达，不做弹层） |
| 切换一级 | 二级、三级栏跟随重置 |
| 切换二级 | 三级栏跟随重置 |

进入页面时：定位树中第一个一级项（一级为空时取第一个二级项）作为当前分类并拉书。

---

## 八、筛选设置

- **内容**：书源面板中的所有 select（状态、性别、字数、时间、排序等）、text 输入、开关型 button
- **存储**：按书源独立保存，与分类树分离
- **生效时机**：自动应用——进入列表页时、点击任一分类节点拉书时，都会先按存储顺序执行各控件的动作，再加载列表

---

## 九、节点执行流程（统一）

点击任一分类节点时，按以下顺序执行：

1. 应用筛选设置（按存储顺序执行各控件 action）
2. 按节点类型执行：
   - url：直接加载该 url 的书籍列表
   - select 选项：先执行其 action 切换语境（写入源变量），再加载该 select 的默认列表（优先"全部"项 url，其次第一个 url 项，都没有则仅刷新面板）
   - button：仅执行 action，不拉书；执行后面板若发生变化，刷新面板并提示
3. 页码重置为第 1 页

---

## 十、失效处理与容错

- 节点点击时按其类型在当前面板中查找匹配项：url 比对地址字符串；select 选项比对控件标题 + 选项名；button 比对标题
- 匹配不到时提示"该分类已失效，请重新添加"，节点保留显示
- **不做自动清理、不做自动重映射**（按已确认决策）
- 书源面板刷新（切换站点、切换模式、reUiView 回调）后，已存节点照旧显示，点击时再校验

---

## 十一、数据存储设计（逻辑描述）

按书源维度存储，位于应用本地配置中，键名为 `exploreCats_{书源地址}`，包含两部分：

**筛选设置**：一组"控件标题 → 选中值"的映射，独立保存。

**分类树**：三级树形结构。每个节点包含：
- 显示名称（用于 chip 展示）
- 类型（url / select 选项 / button）
- 原始引用（控件标题、url、选项名等，用于执行与失效校验）
- 子节点列表（最多两级嵌套）

失效节点保留在树中不删除；同名不同引用的节点允许共存。

---

## 十二、完整交互流程

```
进入书源列表页
  → 首次进入：预填（成功→两级树；失败→二级平铺）＋ 自动应用筛选设置
  → 三栏平铺展示，定位第一个一级项（或第一个二级项）拉书

点击右上角「筛选」
  → 筛选页：已选三栏 + 筛选设置 + 传统发现面板
  → 面板点 url 分类 → 弹菜单「添加一级/二级/三级/取消」（按辖域与跳过规则过滤）
  → 面板点 select → 展开选项 → 点具体选项 → 弹添加菜单
  → 筛选设置调整 → 改动即存、自动应用
  → 返回列表页：三栏刷新，按新树定位拉书

点击任一栏 chip → 高亮 + 联动刷新下级栏 + 按节点语义拉书
```

---

## 十三、与旧方案的关系

- 旧「自动大分类栏」（按占满一栏判断大分类）不再作为运行时规则
- 其判断逻辑降级为**首次预填**使用：判断成功则生成两级骨架，判断失败则平铺
- 运行时展示完全由用户手动构建的分类树驱动

---

## 十四、需要实施时特别留意的边界

1. select 选项作为二级节点后，其三级的候选范围仍受同一 select 值域约束（严格限定的自然延伸）
2. 书源切换站点/模式导致整个面板结构变化时，已存树可能全部失效，但按决策保留显示、点击时逐个提示
3. 预填与用户树的关系：预填只出现在首次、且从未手动编辑时；「清空重建」可主动触预填

## 十五、v2 追加：分类编辑弹窗（2026-10-03 拍板）

用户反馈 280dp 侧滑抽屉过窄、分类挤压。参照全宽弹窗+页签+胶囊网格多选模式重构编辑入口。

### 15.1 结构（自上而下）

1. 标题栏「分类设置」+ 右上角关闭
2. 功能入口行：「筛选设置」「书源登录」，条件显示
   - 筛选设置：`filterSettingKinds()` 非空时显示；点击弹二级弹窗（复用 FILTER_SETTINGS 渲染，改动即存+执行 action，关闭后 onPanelChanged 刷新网格）
   - 书源登录：`loginUrl`/`loginUi` 非空时显示；跳转 `SourceLoginActivity(key=sourceUrl, type="bookSource")`
3. 层级页签：「一级分类」「二级分类」「三级分类」三选一
4. 父级选择行（仅二/三级页签）：横滑 chips；二级页签列全部一级、三级页签列全部二级；默认第一个，紫色高亮当前
5. 分类网格：全部 url 分类胶囊流式排布 + select 类型项（点击弹选项列表，选项作为「选项分类」挂当前层级）；已属于当前层级 = 主色高亮
6. 底部按钮行：「清空重建」「清空」（保留确认弹窗与预填逻辑）

### 15.2 交互

- 点击 url 胶囊：toggle 当前层级成员；二级挂父级选择行当前选中一级、三级同理
- 跳级保护：无父级时网格置灰并提示「请先添加一级/二级分类」
- 长按已选胶囊：引用信息弹窗（可删除）
- 关闭弹窗：saveInfoMaps + onFilterClosed（沿用现状语义）

### 15.3 移除项

- DrawerLayout 侧滑抽屉与 view_explore_show_drawer 使用（布局文件暂留）
- 「＋」chip、showAddMenu 弹菜单添加（被 toggle 网格取代）

### 15.4 技术要点

- 新增 `CategoryEditDialogFragment` + `dialog_category_edit.xml`；筛选设置二级弹窗同文件
