# 播放器按钮与片头片尾

## 需求

1. 当显示控制栏时，播放器应以圆形中央播放按钮、右侧悬浮锁屏按钮和底部图标标签呈现操作，参考用户提供的 HTML 样式。
2. 当用户点击片头或片尾按钮时，播放器应提供关闭、预设秒数和当前位置标记选项，并保存配置。
3. 当播放进入已配置的片头区间时，播放器应自动跳至片头结束点，每次播放处理一次。
4. 当播放进入已配置的片尾区间时，播放器应通过现有完成回调处理连播。
5. 当流为已识别直播、时长未知或配置区间重叠时，播放器应保留正常播放。
6. 当用户切换全屏时，播放器应保留已处理标记；当切集时，应重置标记。
7. 当锁屏时，播放器应保留可点击的解锁入口。
