# 原生播放器控制栏与跳过流程

保留 GSY 播放内核，使用 Android XML、矢量图标与渐变背景实现参考页面的视觉布局。保留原有清晰度、静音等可用操作，片头片尾按钮在两种模式下均提供入口。

VideoPlayer 负责配置对话框、按钮状态、进度检查和锁屏显隐。VideoPlay 已有配置作为持久化来源，IntroOutroSkipPolicy 负责独立的区间和标记位置校验。

片头使用 seekTo；片尾使用 onAutoCompletion 并交给既有 Activity 回调处理下一集。处理标志在发起动作前设置，避免进度回调重入。全屏复用共享标志，拖动回到片头区间保留已处理状态。

## 验证

纯 Kotlin 单元测试验证时长、区间重叠、整数边界及当前位置换算；构建 assembleAppDebug 验证资源与绑定。设备验收覆盖配置保存、全屏切换、锁屏解锁、手动拖动及书源/RSS 连播。
