# Book Search Page Design

Updated: 2026-11-17

SearchActivity retains existing external start overloads and hosts a book-specific Compose screen. SearchViewModel and SearchModel retain the existing book-source engine, aggregation, cancellation and paging. A callback capability opts the book search page into BookSearchQuery rules so other SearchModel clients keep their previous matching behavior.

BookSearchQuery splits the final whitespace-separated author component, supplies the title to source requests and applies author equality independently of exact title matching. Advanced filters operate on collected SearchBook results and trigger a new search on setting changes. History uses the existing Room table with retention capped at 20 on write.

BookSearchScreen uses a fixed rounded filled search field with an integrated submit button and a unified lazy grid for source pills, history, three-column recommendation cards and list/grid results. Exact-title selection sits in the source-range header. Search results hide recommendations until the result-row toggle is activated. A horizontal address switcher lists configured discovery addresses. Overflow settings edit local drafts; confirmation persists preferences and hot selections. Result clicks open BookInfoActivity; recommendation clicks use the shared keyword submit action.

The active discovery address is session state, separate from persisted configured selections. Switching cancels obsolete refreshes, clears cards from the previous address and reloads the selected address through its existing cache key. Source changes and configuration changes reset an invalid active address to the first configured address. The switcher lists concrete addresses only. Discovery cards and loading skeletons use three columns, with grid spans divisible by both three and the result column count. Source groups use one horizontal scroll row with a labeled multiple-selection checkbox. The hot-source dialog filters the eligible source list by name or URL while keeping draft selections independent of the query. The main input uses a 32dp submit button with 3dp vertical insets.

SearchHotViewModel observes eligible sources, lazily resolves discovery fragments through exploreKinds, and loads selected fragments through WebBook.exploreBookAwait. Each request has a 15-second timeout; a semaphore limits concurrency to four. Source/address caches expire after 30 minutes. Completion sequence selects duplicate-title winners while final output follows configured address order. Versioned jobs prevent stale results after configuration or source changes.

Validation: query and filter unit tests, hot merge tests, compilation and assembleDebug. Manual device checks cover narrow-screen controls, wrapping groups, keyboard submission, state restoration, partial network failures and unchanged RSS/video entries. Completion filtering uses source-provided kind/latest-chapter markers; unknown word counts appear only with the unrestricted threshold.

Recommendation settings flatten source headers and expanded addresses into one reorderable lazy list using sh.calvin.reorderable. Stable keys support filtered source lists and edge autoscroll. Selected-first partitions stay fixed; dragging changes order within each partition. Source and address order preferences are JSON arrays/maps committed alongside selected-address drafts only on confirmation. Group/address pills use 12dp horizontal and 7dp vertical padding; history uses 10dp and 6dp.

The related homepage source manager is an independent HomeSourceManageActivity using AppManagementScaffold. HomeSourceManagementStore persists named groups separately from source files, includes configurations without usable stations, and revalidates the complete affected configuration before deletion. HomepageFragment refreshes sources when the manager returns. Expanded configuration stations share a deletion scope, explicitly shown in the confirmation dialog. Discovery groups use a dedicated text-color selector; normal-player fullscreen uses a 28.8dp thicker icon in its existing 40dp touch target.
