# 统一播放器全屏验收

1. 当沉浸式模式 0（含浮窗恢复）或详情合页模式 1 请求全屏时，播放器应显示同一套现有 `video_layout_controller_full` 控件。
2. 当退出全屏时，播放器应恢复进入前的普通页面、屏幕方向、系统栏和 ViewPager 输入状态，并保持播放进度、暂停状态、倍速、比例、静音和弹幕状态。
3. 当全屏窗口显示时，沉浸式 Fragment 应挂起普通页面控制层、自动隐藏、缓冲 UI 更新和手势，并恢复长按前倍速；退出后应恢复普通控件与触摸监听。
4. 当用户重复请求退出、接收新 Intent、切换布局或转移至浮窗时，播放器应在宿主释放或转移前完成一次全屏状态回拷。
5. 当异步解析期间进入或退出全屏时，解析结果应经既有 token 校验后提交到当前播放实例；相邻 Fragment 释放应仅操作自身播放器。
6. 跳过片头和片尾按钮应保留用户设置的 BLUE/WHITE 颜色。

## 手工验收

- 两种模式分别测试横屏、竖屏视频，全屏按钮、返回按钮、系统返回、连续点击退出。
- 全屏内测试暂停、拖动、倍速、比例、静音、锁定、选集、线路和弹幕，退出后检查状态一致。
- 延迟解析时反复进出全屏，再切集，确认最终视频、标题和请求头对应当前集。
- 全屏内切换布局、接收新播放 Intent、进入浮窗并恢复模式 0，确认画面、音频和控件正常。
- 文章模式与单页书源分别确认退出后 ViewPager 保持原输入状态，相邻页回收保持当前播放。
