# 定时任务帮助

定时任务由五字段 Cron 驱动，按计划执行一段同步 JavaScript；脚本的最终返回值按「返回协议」解析为动作（更新目录 / 发通知）。脚本环境与书源规则一致（`java.*` 可用），并复用登录、Cookie 与缓存能力。

## Cron 表达式

格式：`分 时 日 月 周`，五字段、以空格分隔。按设备本地时区运行，最小粒度一分钟。

| 表达式 | 说明 |
|--------|------|
| `*/5 * * * *` | 每 5 分钟 |
| `0 9 * * *` | 每天 09:00 |
| `0 9 * * 1` | 每周一 09:00 |
| `0 0 1 * *` | 每月 1 日 00:00 |
| `0 8,20 * * *` | 每天 08:00 和 20:00 |
| `*/30 6-23 * * *` | 06:00～23:00 之间每 30 分钟 |
| `30 9 1-7 * 1` | 每月 1～7 日的 09:30，以及每个周一的 09:30 |

符号：

- `*` 任意值；`?` 同 `*`
- `,` 列表（多个值）
- `-` 范围
- `/` 步长

取值范围：分 `0-59`，时 `0-23`，日 `1-31`，月 `1-12`，周 `0-7`（周日可写 `0` 或 `7`）。

> 日与周同时受限时按 **OR** 匹配，不是 AND：`30 9 1-7 * 1` 匹配「每月 1～7 日的 09:30」或「每个周一的 09:30」，而不是只匹配两者交集的时刻。

## 返回协议

脚本需要返回 **JSON**，支持三种形态：

**1. 动作数组**
```json
[
  { "type": "refreshToc", "bookUrl": "https://..." },
  { "type": "notify", "title": "完成", "content": "全部更新完毕" }
]
```

**2. 单个动作对象**（须含 `type`）
```json
{ "type": "notify", "title": "签到", "content": "已签到 {time}" }
```

**3. 包裹在 actions 中**
```json
{
  "actions": [
    { "type": "refreshToc", "bookUrl": "https://..." }
  ]
}
```

返回 null 或无法解析时视为无动作，不报错。

## 支持的动作

### type: refreshToc — 更新书籍目录

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | string | ✓ | `"refreshToc"` |
| `bookUrl` | string | ✓ | 书架中书籍的绝对 bookUrl，按此精确匹配 |
| `notify` | object | | 更新通知配置；不写则更新后不发通知 |
| `cache` | object | | 自动缓存新章节配置 |

**notify 子对象**（存在时下列字段可选、缺省值生效；无新增章节时不发通知）：

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `enable` | boolean | true | 是否发通知 |
| `minCount` | number | 1 | 至少新增多少章才通知 |
| `title` | string | 内置文案（随界面语言） | 通知标题，支持占位符 |
| `content` | string | 内置文案（随界面语言） | 通知内容，支持占位符 |

**cache 子对象：**

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `enable` | boolean | false | 是否自动缓存新章节 |

**完整示例：**
```json
{
  "type": "refreshToc",
  "bookUrl": "https://example.com/book/123",
  "notify": {
    "enable": true,
    "minCount": 5,
    "title": "《{book}》更新了！",
    "content": "作者 {author} 新增 {newCount} 章\n最新：{chapter}\n时间：{time}"
  },
  "cache": {
    "enable": true
  }
}
```

---

### type: notify — 发送通知

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | string | ✓ | `"notify"` |
| `title` | string | | 通知标题，默认「任务通知」 |
| `content` | string | | 通知内容，默认任务名 |
| `level` | string | | 优先级：`high`/`error`/`fail`/`failed` 为高，`low` 为低，其余为普通 |
| `id` | number | | 通知分组 id，相同 id 的通知互相替换；缺省按任务名+标题+内容生成稳定 id |

```json
{
  "type": "notify",
  "title": "每日签到",
  "content": "已完成\n时间：{time}",
  "level": "high",
  "id": 1
}
```

---

## 占位符

**refreshToc 通知中可用：**

| 占位符 | 替换为 |
|--------|--------|
| `{book}` | 书名 |
| `{author}` | 作者 |
| `{newCount}` | 新增章节数 |
| `{chapter}` | 最新一章标题 |
| `{time}` | 当前时间（MM-dd HH:mm） |

**notify 通知中可用：**

| 占位符 | 替换为 |
|--------|--------|
| `{task}` | 任务名称 |
| `{time}` | 当前时间（MM-dd HH:mm） |

---

## 任务字段

编辑页可配置：名称、启用开关、Cron、脚本、备注；请求与登录环境字段：请求头、jsLib、并发率、登录URL/登录UI/登录检查JS、启用CookieJar（与书源同语义）。脚本可直接写 JavaScript，也兼容外层 `@js:` 或 `<js>...</js>` 包裹。运行状态字段（上次运行时间/结果/错误/日志）由应用维护，导入时无需填写。

## 调试与导入

- 编辑页右上角菜单 →「调试」：单次运行当前脚本并在对话框查看执行日志。
- 管理页支持导入/导出任务 JSON；定时任务服务开关在设置中开启后才会按 Cron 调度。
